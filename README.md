# First-person_shooter
First-person shooter
Some notable features include:  
1. Customizable key bindings  
2. Weapon inspection  
3. Wyvern jet dash  
4. Wyvern C4 bomb  
5. Variety of enemies, weapons, and attribute-enhancing attachments  
6. Adjustable graphics quality settings  
7. Scene colors adapt to browser settings  
8. Full-screen immersive gameplay support  
9. The game actually supports gyroscope input, but using it is complicated and requires a server (computer)
